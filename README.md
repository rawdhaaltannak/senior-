# Smart Health Monitoring Application

## Project Overview
A smart health management application developed by students at the University of Sharjah. The application helps users manage and monitor their health information through an integrated digital platform.

## Main Features
- Health information management
- Appointment management
- Meal management
- Firebase database integration
- AI-powered health insights using Gemini
- User-friendly application interface

## Technologies Used
- Firebase
- Gemini AI
- Mobile application development
